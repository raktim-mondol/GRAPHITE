Overview
--------

GRAPHITE is a cutting-edge explainable AI framework that combines deep learning with graph attention mechanisms 
to provide interpretable machine learning solutions. It specializes in saliency map fusion for enhanced 
model transparency and understanding.

Key Features
------------

* **Graph Attention Networks**: Advanced attention mechanisms for improved model interpretability
* **Saliency Map Fusion**: Sophisticated fusion techniques for multi-modal explanation
* **Explainable AI**: Comprehensive tools for understanding model decisions
* **Deep Learning Integration**: Seamless integration with popular deep learning frameworks
